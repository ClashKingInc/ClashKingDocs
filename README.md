# ClashKing Docs (Docusaurus)

This repository contains the ClashKing documentation migrated from GitBook to [Docusaurus](https://docusaurus.io/).

## Install

```bash
npm install
```

## Local development

```bash
npm start
```

## Production build

```bash
npm run build
```

The legacy GitBook export folder (`ClashKingDocs-master/`) is intentionally ignored in `.gitignore`.
