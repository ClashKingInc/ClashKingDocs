# 🏗️ Autoboards

Autoboards automatically keep leaderboards available in your Discord server.

:::warning
This feature is in **open beta**.
:::

## Available leaderboards

- **Donation leaderboard**: show the top 1–50 donors across your family or selected clans. You can refresh one message or send a new message on a schedule.
- **Farming leaderboard**: show the top 1–5 current members of one selected clan, based on recorded farming attacks. Choose the current game season or a rolling period of 1–180 days. This board refreshes one message.

## Create an autoboard

1. Open the ClashKing dashboard, select your server, and open **Autoboards**.
2. Click **Create AutoBoard** and choose a leaderboard type.
3. Choose the family or clans to include, as supported by the selected board. Add clans to your server first if they are not available to select.
4. Choose a Discord channel and, if needed, a thread or forum post. A forum destination requires a post.
5. Set the number of players to show. For farming, also choose the farming window and, for a rolling period, the number of days.
6. For donations, choose **Refresh** to update the same message, or **Scheduled send** to post a new message daily, on selected weekdays, or on a selected day of the month. Scheduled times are in UTC.
7. Set the refresh interval if the dashboard allows it, choose whether the board is enabled, and click **Create AutoBoard**.

## Manage autoboards

The dashboard lists your configured boards and lets you edit, disable, or delete them. A disabled board keeps its settings but does not run. To have both a refreshed donation board and scheduled donation posts, create a separate board for each.
