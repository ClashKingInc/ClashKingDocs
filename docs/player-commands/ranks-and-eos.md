# 🏆 Ranks & EOS

Use the Ranked commands in Discord to view a player's current tournament, group standings, and recorded season history. EOS means end of season.

## View a Ranked player

Run `/ranked player` and select a **player** or enter their tag. By default, the command shows their current Ranked tournament: league, trophies, group position, recorded attacks and defenses, and a season graphic. The player must be in a current Ranked tournament for this view.

Optionally, enter a numeric **season** ID to view a recorded past tournament for that player instead. Historical information depends on the data available for that season.

Use **Player** and **Group** below the result to switch between the player's overview and the group standings. The group shows player positions, trophies, and attacks; use its navigation buttons for longer lists. Promotion and demotion scores in the current season graphic are current group cutoffs, not guaranteed final results.

## View Ranked season history

Run `/ranked history` and select a **player** or enter their tag to see recorded Ranked seasons, including league, trophies, placement, and attack counts. Use the navigation buttons when the history spans multiple pages.

## Other rankings

For official global or country leaderboards, use `/leaderboard location`; see [Leaderboards](../clan-and-family-commands/leaderboards.md). For Legend League statistics and season finishes, see [Legends](legends/README.md).
