# 🙎‍♀️ Accounts check

Use `/link list` in a Discord server to check linked accounts for yourself, another Discord user, or a clan linked to the server.

## Check a user's accounts

Run `/link list` without options to see your own visible linked accounts. To check someone else's accounts, select them with the optional **discord_user** option.

The list shows each available player's Town Hall, verification status, name, trophies, and clan. Hidden accounts are excluded. Use the navigation buttons for longer lists and the refresh button to update the result.

For example, select a clanmate as **discord_user** to see their visible linked accounts. To inspect an individual account in more detail, use [Player lookup](lookup.md).

## Check a clan's accounts

Select a server-linked **clan** instead of a Discord user to see its members grouped by link status: linked and in the server, not in the server or hidden, and not linked. The list includes Town Hall levels and verification indicators where available. Use the clan selector to switch clans and the refresh button to update the list. You can select either **clan** or **discord_user**, not both.

See [Link players](../bot-commands/link-players.md) for linking and managing accounts.
