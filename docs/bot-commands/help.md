# 🆘 Help

Use `/help` to browse ClashKing's available Discord commands and see what they do.

## Browse commands

Run `/help` without options to see the command overview. Use the **Browse commands** dropdown to choose a category, such as **Players & rankings**, **Clans & wars**, or **Your accounts**. Choose **All commands** to return to the full overview. The refresh button updates the current view.

## Find a command

Use the optional **command** field and select a current command from Discord's suggestions. For example, choose `link add` to see a description of `/link add`. Selecting a command with subcommands shows its available subcommands; selecting a specific subcommand shows its description and its required or optional fields.

You can instead use the optional **category** field to open a category directly. For longer setup guides, browse the rest of these docs.
