# 👥 Role users

Use `/role-users` in a Discord server to list members with a specific Discord role.

## Find members with a role

Run `/role-users` and select the required **role**. For example, select a clan leadership role to see which server members have it. The result includes the member count; use the navigation buttons for longer lists and the refresh button to update the result.

To configure ClashKing's automatic roles, see [Roles & Nicknames](../dashboard/roles-and-nicknames.md).
