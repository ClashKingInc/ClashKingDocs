# 🎨 Fankit

Use `/fankit` to search ClashKing's game artwork, including troops, heroes, and buildings.

## Find an image

Run `/fankit` and enter a **query**, for example `Archer Queen`. The result shows matching images. Use **Previous** and **Next** when there are multiple pages.

In a server, use **Add Emoji** next to an image to add it as a server emoji. You and the bot need permission to create expressions, and the server needs an available emoji slot. The button is unavailable outside a server.
