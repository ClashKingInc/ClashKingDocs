# 📋 Roster commands

Use these commands in Discord to publish an existing roster or find a player's rosters. Create and manage rosters in the [dashboard](../clans-management/rosters/README.md).

## `/roster post`

Publish an existing roster in the current channel. Select the **roster** and a **type**:

- **Signup**: includes buttons for players to sign up or remove a signup.
- **Post**: displays the roster without signup buttons.
- **Static**: posts a snapshot.

This command requires **Manage Server** or **Administrator** permission. You can also post from the dashboard and choose the destination there.

## `/roster search`

Find this server's rosters for a **player** (select a player tag) or a **user** (select a Discord user). Choose one of the two; if neither is provided, the command searches your own visible linked accounts.
