# 📈 Graphs

Use `/graph` to explore clan and family statistics.

## Command

- **Command:** `/graph`
- **Description:** `Explore clan and family statistics`

The command supports **3 optional parameters**.

## Options

| Parameter | Description |
|---|---|
| `attribute` | Statistic (default: Activity) |
| `clan_category` | Family clan category (default: all family clans) |
| `limit` | Clans to compare (default: 5) |

## Defaults

- `attribute`: `Activity`
- `clan_category`: all family clans
- `limit`: `5`

Fill in any of these options to compare clans or focus on a specific statistic. If you leave them empty, the command uses the default values above.
