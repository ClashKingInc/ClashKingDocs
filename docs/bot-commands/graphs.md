# 📈 Graphs

Use `/graph` in your Discord server to compare statistics across your family clans. [Add clans to the server](../dashboard/add-setup-a-clan.md) first; you can also assign categories there.

## Run the command

All three options are optional:

- **attribute**: choose a statistic. The default is **Activity**.
- **clan_category**: limit the family clans to a category. Leave it empty for all family clans.
- **limit**: choose how many clans to compare initially, from **1 to 5**. The default is **5**.

For example, run `/graph` for an Activity chart, or select **Donations** as the attribute and a clan category to compare donations within that group. With no options, Activity opens as a daily trend over the past 30 days.

## Change the graph

Use the controls beneath the graph to change the **Statistic**, **Chart view**, or selected clans without running the command again. The clan menu allows you to choose individual clans or return to all family or category clans. A refresh button reloads the current view.

Depending on the statistic, the following views are available:

- **Daily trend**: compare daily values over 7, 30, 90, or 180 days.
- **Season totals**: compare totals for the current or a selected season.
- **Season trend**: compare trends over 2, 4, 6, or 12 seasons. CWL league uses this view.

## Available statistics

Choose from activity, upgrades, donations, troops received, joins and leaves, Capital Gold donated or raided, gold, elixir and dark elixir looted, war stars, war win rate, wars won or started, and CWL league. Daily trends are available for activity, upgrades, donations, troops received, Capital Gold donated, and joins and leaves.

:::info
Graphs depend on available recorded data. Some clan totals or historical observations may be unavailable.
:::
