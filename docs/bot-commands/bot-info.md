# 🤖 Bot information

Use `/bot` to see ClashKing statistics and useful links.

## View bot statistics

Run `/bot` to view available counts, such as servers, linked clans, tracked players and clans, and recorded wars. Additional counts are shown when available. Use the refresh button to reload the statistics, or use **Bot Invite** and **Support Server** to open the relevant links.
