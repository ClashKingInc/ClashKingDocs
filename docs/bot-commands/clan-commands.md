# 🏛️ Clan commands

Use the clan commands in Discord to inspect a clan's profile, members, and recorded statistics. Each command below requires a **clan**; select one by name or tag. Optional inputs depend on the command, and some reports offer additional menus or refresh buttons below the result.

The images are older examples. The current layout, values, and controls may differ.

## Clan overview

Use `/clan search` to view a clan profile. Optionally choose **type**: Detailed (default), Basic, or Minimalistic.

## Activity

Use `/clan activity` to see recorded activity for current clan members. Optionally choose **season** (`YYYY-MM`), **limit**, **sort_by**, and **sort_order**. Last-online sorting is available for the current season. The older example includes a graph that is no longer part of this report; use [Graphs](graphs.md) for charts.

## Donations

Use `/clan donations` to view donated and received troops. Optionally choose a **season** (`YYYY-MM`), **current_members**, and **limit**. Use the result controls to change the sorting.

## Clan Capital

Use `/clan capital` to view raid weekend information. Optionally select **weekend** using a Friday date (`YYYY-MM-DD`); the latest weekend is used by default. Use the result menu to view the overview, raiders, or recorded donations.

## Sorted members

Use `/clan sorted` to rank current members by a statistic. Optionally set **limit**, then use the result controls to choose the statistic. For example, compare members by Town Hall or war stars.

## Upgrade progress

Use `/clan progress` to see recorded unit upgrade changes for current members. Optionally specify a **season** (`YYYY-MM`); without it, the report uses the last 30 days. Choose the upgrade type in the result menu. The older examples show previous layouts.

Use `/clan war-log` to see war history or CWL season history. Optionally choose **view** and **limit**. A private war log or missing recorded data can limit the results.
