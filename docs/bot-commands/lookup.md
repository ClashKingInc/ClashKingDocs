# 🔍 Lookup

Use `/player lookup` in Discord to view a player's profile, troops, progress, and clan history.

## Look up a player

Both options are optional:

- **player**: select a player or enter a player tag. When supplied, this account is shown.
- **discord_user**: select a Discord user to look up their visible linked accounts.

If you omit both options, ClashKing looks up your own visible linked accounts and opens the one with the highest Town Hall level. If there are no visible linked accounts, provide a player tag or [link an account](link-and-unlink-players.md). If both options are provided, **player** takes precedence.

For example, select a clanmate as **discord_user** to view their linked accounts, or enter their player tag directly.

## Browse the profile

Use **Choose a page** below the result to switch between:

- **Overview**: profile and available player statistics.
- **Troops**: troop, spell, hero, pet, equipment, siege machine, and Builder Base levels when available.
- **Progress**: upgrade completion and remaining levels, time, and costs where available.
- **Clan History**: recorded history, with buttons to switch between ClashKing and Clash of Stats.

When looking up a Discord user, **Choose an account** appears if that user has more than one visible linked account. It lets you switch accounts. Some pages also have navigation buttons for longer results.
