# 🎫 Tickets

Tickets can be set up on the dashboard. From Discord, you can manage them with the following commands.

## /ticket status

Use `/ticket status` with one of these arguments:

- `open`
- `sleep`
- `close`

## /ticket add

Use `/ticket add` with a **player** argument to add someone to a ticket.

## /ticket messages

Use `/ticket messages` to easily send prepared messages in Discord. Prepare these messages on the dashboard first.
