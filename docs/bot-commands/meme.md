# 🐸 Memes

Use `/meme` to create a Clash-themed meme or a Pepe sign with your own text.

## Create a meme

1. Run `/meme` and select a template from **Choose a meme template**.
2. Fill in the captions and submit the form.
3. Save or copy the generated image to share it. Use **Write again** to change the text or choose another template.

For example, choose **Pepe sign** and enter the text you want on the sign. The preview is visible only to you until you share the image.
