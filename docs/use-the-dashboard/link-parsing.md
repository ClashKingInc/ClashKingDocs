# 🔗 Army & Base Sharing

Use Discord commands to share an army as a readable overview or post a base with screenshots and feedback buttons.

## Share an army

Run `/army link` in a server and provide:

- **army** (required): a Clash of Clans army link or share code.
- **nickname** (required): a name for the army.
- **notes** (optional): additional information for the message.

For example, give an army a name and add notes explaining how to use it. The result shows the available army composition and has a **Copy Army** button. If the link contains Clan Castle troops or hero loadouts, the overview can show those too.

## Save and share an army

Click **Save Army** on an army result to add it to your ClashKing army library. To share a saved army, run `/army share` and select it from the menu. Sign in to the ClashKing app with Discord to use your library. If your library has more than 25 armies, remove the extras in the app before sharing through the bot.

## Share a base

Run `/base` in a server to open the form. Provide a Clash of Clans base link, a description, and one to four screenshots. Supported image formats are PNG, JPEG, GIF and WebP, up to 25 MB per image. Submit the form to post the base in the channel.

For example, describe the Town Hall level and intended use of the base, then add a screenshot. Other members can use the link button to get the base link and vote with the feedback buttons. The post displays the download count.

## Parse links automatically

To automatically expand supported army and base links posted in messages, configure [Link parsing](../server-setups/link-parse.md) in the dashboard. That page also includes examples.
