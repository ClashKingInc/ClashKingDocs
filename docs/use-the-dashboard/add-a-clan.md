# ➕ Add a clan

Under **Management** in the dashboard, you can add a clan to your server. This lets you manage that clan and its settings from the dashboard instead of only through Discord commands.

## Verify a clan

To prove that a clan belongs to your server, temporarily add a verification word to the clan's in-game description.

Once the clan is verified:

- Hidden account links in the clan roster become visible.
- Dashboard Links managers can add or remove unverified links for its members.
- Already verified player links remain protected.

After verification succeeds, you can remove the word from the clan description.
