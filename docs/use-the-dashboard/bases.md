# 🗺️ Bases

Use **Management → Bases** in the dashboard to publish and manage your server's base layouts. This page requires full dashboard access.

## Publish a base

1. Open **Bases** and choose **Create**.
2. Select a Discord channel, enter the Clash of Clans layout link and description, and add the required screenshots.
3. Submit the form and check the result. Members can obtain the link and vote on the Discord message.

For example, describe the Town Hall level and whether a base is intended for war or farming. You can also publish a base from Discord with [`/base`](link-parsing.md).

## Manage published bases

The list shows available screenshots, downloads, and votes. Open the layout or Discord message, inspect download history, edit a base, or delete it using its controls. Review the confirmation before deleting. Use refresh and pagination to browse the list.
