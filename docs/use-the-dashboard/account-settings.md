# 👤 Account Settings

Use **Account Settings** to manage your dashboard preferences and view server information.

## Profile and appearance

Open **Settings** from your account menu. Under **Profile**, choose a dashboard theme and language, or follow the system theme and browser language. You can also choose whether to hide support prompts. These are dashboard preferences.

## Server and Lab

When a server is selected, **Server** shows its resource limits. **Lab** is available to users who can view server settings and contains experimental features. Currently, you can enable Discord tenure roles there, then configure them in **General settings**; see [Roles & Nicknames](../players-roles/roles-th-and-more/README.md). Managing the experiment requires settings management access.
