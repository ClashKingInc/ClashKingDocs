# 🖥️ Dashboard explained

The **dashboard** makes it easy to manage your Discord server settings for ClashKing in one place.

## How to reach the dashboard

You can reach the dashboard in two ways:

- Go to [https://clashk.ing/login](https://clashk.ing/login)
- Use the `/setup` command in a Discord server where ClashKing is installed

:::info
ClashKing must be in your server. Access requires server ownership, **Manage Server**, **Administrator**, or a role granted [dashboard access](../server-setups/whitelist.md).
:::
