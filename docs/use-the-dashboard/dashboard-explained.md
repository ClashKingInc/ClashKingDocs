# 🖥️ Dashboard explained

The **dashboard** makes it easy to manage your Discord server settings for ClashKing in one place. Some settings that used to be configured through the Discord bot have moved to the dashboard.

## How to reach the dashboard

You can reach the dashboard in two ways:

- Go to [https://clashk.ing/login](https://clashk.ing/login)
- Use the `/setup` command in a Discord server where ClashKing is installed

:::info
You need the ClashKing bot in your server and be an **admin** or the **server owner** to use the dashboard.
:::
