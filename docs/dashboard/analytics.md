# 📊 Analytics

Analytics shows recorded activity and trends for the clans connected to your server. The feature is in **beta**.

## Explore the dashboard

Open **Management → Analytics** and select a period. Choose a preset or a custom date range, and select a clan to narrow the report. Add clans to the server first if none are available; see [Add / Setup a clan](add-setup-a-clan.md).

The report includes member totals and movement, Town Hall and league composition, clan comparisons, recorded activity and upgrades, and Legend finishes when data is available. Select a metric to change the activity calendar and player ranking. Click a day or player to open more detail; use search and pagination for longer lists.

For example, select a clan and a date range to compare recorded donations or farming activity. The report uses tracked observations, so missing data should not be interpreted as zero activity. Link statistics are shown when you have permission to view Links.
