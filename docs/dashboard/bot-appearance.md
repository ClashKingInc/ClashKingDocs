# 🎨 Bot Appearance

Use **General settings** in the dashboard to configure your server's bot appearance, link parsing, and access settings.

## Customize the bot profile

Open **General settings** for your server and find **Bot server profile**. If profile customization is enabled for your server, you can change the bot's server name, bio, avatar, and banner. Changes are saved from the profile card; use the reset controls to return individual fields to the global profile. Editing requires settings management access. If the feature is locked, use the displayed support link to request access.

## Choose the embed color

Under **Appearance**, select an embed color and review the preview. This color is used by supported bot messages. Settings are saved in the dashboard.

## Other settings

- Configure [Dashboard access](dashboard-access.md) and the role refresh delegate under **Security & Permissions**.
- Turn supported link types on or off under **Link parsing**; see [Link parsing](link-parsing.md).
- Enable Discord tenure roles in **Lab** before configuring them here; see [Roles & Nicknames](roles-and-nicknames.md).
