# 🏠 TownHall-rollen

## Het doel

Geeft een specifieke rol aan gebruikers, afhankelijk van hun huidige stadhuisniveau.

<figure><img src="/img/gitbook/image (124).png" alt="" /><figcaption></figcaption></figure>

## Het commando

Daarvoor moet u de opdracht `/roles townhall` gebruiken.

:::info
Voordat u die opdracht uitvoert, moet u de rollen aanmaken die u wilt instellen in de instellingen van uw Discord-server.
:::
