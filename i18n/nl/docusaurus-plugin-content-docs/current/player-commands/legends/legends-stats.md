# Legends-statistieken

## Het commando

`/legends stats {type}`

## De parameter

* `type:` heeft 4 verschillende opties:&#x20;
  * Ranglimiet
  * Triple Streaks, met een optie voor `{limit}` het aantal resultaten tussen 1-50
  * Trofee-emmers
  * EOS-afwerkeenheden
