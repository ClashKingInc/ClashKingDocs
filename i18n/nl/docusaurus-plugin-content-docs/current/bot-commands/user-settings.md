# 😎 Gebruikersinstellingen

Kies een gekoppeld hoofdaccount voor elke Discord-server waar je ClashKing gebruikt.

## Kies je hoofdaccount

1. Koppel je account met `/link add` als je dat nog niet hebt gedaan. Zie [Link players](link-and-unlink-players.md).
2. Gebruik in de Discord-server `/link set-main` en selecteer een van je zichtbare gekoppelde accounts als **player**.
3. Controleer het antwoord van de bot. ClashKing slaat de keuze op voor die server en start een verversing van je bijnaam.

Gebruik je bijvoorbeeld verschillende accounts in twee servers, dan kun je voor elke server een ander hoofdaccount kiezen. De keuze wordt gebruikt bij het bijwerken van je bijnaam volgens de ingestelde regels van die server. Het aanpassen van bijnamen hangt ook af van de rechten van de bot; zie [Manual refresh](manual-refresh-roles-and-nicknames.md).

## Accounts opzoeken

Het gekozen hoofdaccount voor de server bepaalt niet welk account `/player lookup` opent. Zonder opgegeven speler of Discord-gebruiker opent lookup je zichtbare gekoppelde account met het hoogste stadhuisniveau. Je kunt ook rechtstreeks een speler selecteren. Zie [Player lookup](lookup.md).
