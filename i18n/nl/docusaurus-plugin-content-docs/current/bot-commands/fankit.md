# 🎨 Fankit

Gebruik `/fankit` om afbeeldingen van ClashKing te zoeken, waaronder troepen, helden en gebouwen.

## Zoek een afbeelding

Gebruik `/fankit` en vul een **query** in, bijvoorbeeld `Archer Queen`. Het resultaat toont de gevonden afbeeldingen. Gebruik **Previous** en **Next** als er meerdere pagina's zijn.

Gebruik in een server **Add Emoji** naast een afbeelding om deze als serveremoji toe te voegen. Jij en de bot hebben toestemming nodig om expressies aan te maken en de server moet een vrije emojiplek hebben. Buiten een server is deze knop niet beschikbaar.
