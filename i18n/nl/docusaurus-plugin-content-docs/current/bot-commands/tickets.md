# 🎫 Tickets

Tickets kunnen worden ingesteld op het dashboard. Vanuit Discord beheer je ze met de volgende commando's.

## /ticket status

Gebruik `/ticket status` met een van deze argumenten:

- `open`
- `sleep`
- `close`

## /ticket add

Gebruik `/ticket add` met een **player**-argument om iemand aan een ticket toe te voegen.

## /ticket messages

Gebruik `/ticket messages` om voorbereide berichten makkelijk in Discord te verzenden. Stel deze berichten eerst in op het dashboard.
