# 📈 Graphs

Gebruik `/graph` om clan- en familystatistieken te bekijken.

## Commando

- **Commando:** `/graph`
- **Beschrijving:** `Explore clan and family statistics`

Het commando ondersteunt **3 optionele parameters**.

## Opties

| Parameter | Beschrijving |
|---|---|
| `attribute` | Statistiek (standaard: Activity) |
| `clan_category` | Family clan category (standaard: alle family clans) |
| `limit` | Clans om te vergelijken (standaard: 5) |

## Standaardwaarden

- `attribute`: `Activity`
- `clan_category`: alle family clans
- `limit`: `5`
