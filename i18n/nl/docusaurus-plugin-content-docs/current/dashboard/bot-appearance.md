# 🎨 Botweergave

Gebruik **General settings** in het dashboard voor de botweergave, link parsing en toegangsinstellingen van je server.

## Pas het botprofiel aan

Open **General settings** voor je server en zoek **Bot server profile**. Als profielaanpassing voor je server is ingeschakeld, kun je de servernaam, bio, avatar en banner van de bot wijzigen. Wijzigingen worden opgeslagen via de profielkaart; met de resetknoppen zet je afzonderlijke onderdelen terug naar het algemene profiel. Bewerken vereist beheerrechten voor instellingen.

:::info
Botpersonalisatie is beschikbaar voor supporters en contributors. Heb je geen toegang, vraag deze dan aan in de [support Discord](https://discord.gg/clashking).
:::

## Kies de embedkleur

Kies onder **Appearance** een embedkleur en bekijk de preview. Deze kleur wordt gebruikt voor ondersteunde botberichten. De instellingen worden opgeslagen in het dashboard.

## Overige instellingen

- Stel onder **Security & Permissions** [dashboardtoegang](dashboard-access.md) en de rol voor het verversen van rollen in.
- Zet ondersteunde linktypes aan of uit onder **Link parsing**; zie [Link parsing](link-parsing.md).
- Zet Discord tenure roles eerst aan in **Lab** om ze hier in te stellen; zie [Roles & Nicknames](roles-and-nicknames.md).
