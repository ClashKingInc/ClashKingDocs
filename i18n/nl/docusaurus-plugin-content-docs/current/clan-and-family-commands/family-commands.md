# 👩‍👩‍👧‍👦 Gezinsopdrachten

Familiecommando's lijken erg op Clan-commando's, maar op grotere schaal kunnen de hele familie van clans op uw server worden bekeken.

## Topjaren 50

Er zijn een aantal verschillende opties waarmee u de top 50 leden van het hele gezin kunt bekijken, wat handig kan zijn voor vriendschappelijke wedstrijden.

**Er zijn maximaal 6 parameters:**&#x20;

* `{season}` gedraagt ​​zich bij elke opdracht iets anders. Seizoen kan verwijzen naar de maand (clangames) of het in-game seizoen (donaties). Raidweekends hebben in plaats daarvan ook `{weekend}`.
* `{limit}` toont alleen dat aantal gebruikers
* `{townhall}` toont alleen resultaten in dat gemeentehuis
* Met `{sort_by}` kunt u kiezen met welke parameters rekening moet worden gehouden om de top 50 te maken
* `{sort_order}` toont het resultaat in oplopende of aflopende volgorde
* `{server}` toont het resultaat voor een gezin dat is gekoppeld aan een specifieke server **waar u zich bevindt**.
