# ➕ Clan toevoegen

Onder **Management** in het dashboard kun je een clan toevoegen aan je server. Zo kun je die clan en de instellingen ervan beheren vanuit het dashboard in plaats van alleen via Discord-commando's.

## Clan verifiëren

Om te bewijzen dat een clan bij je server hoort, voeg je tijdelijk een verificatiewoord toe aan de beschrijving van de clan in het spel.

Zodra de clan is geverifieerd:

- Worden verborgen accountlinks in de clanroster zichtbaar.
- Kunnen Dashboard Links-beheerders ongeverifieerde links voor leden toevoegen of verwijderen.
- Blijven al geverifieerde spelerlinks beschermd.

Nadat verificatie is gelukt, kun je het woord weer uit de clambeschrijving verwijderen.
