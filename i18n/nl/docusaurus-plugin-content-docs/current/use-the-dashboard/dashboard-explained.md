# 🖥️ Dashboard uitgelegd

Het **dashboard** maakt het makkelijk om je Discord-serverinstellingen voor ClashKing op één plek te beheren. Sommige instellingen die vroeger via de Discord-bot werden ingesteld, zijn verplaatst naar het dashboard.

## Het dashboard bereiken

Je kunt het dashboard op twee manieren bereiken:

- Ga naar [https://clashk.ing/login](https://clashk.ing/login)
- Gebruik het `/setup` commando in een Discord-server waar ClashKing is geïnstalleerd

:::info
ClashKing moet in je server aanwezig zijn. Toegang vereist servereigenaarschap, **Manage Server**, **Administrator** of een rol met [dashboardtoegang](../server-setups/whitelist.md).
:::

Gebruik het dashboard om je Discord-instellingen makkelijker in te stellen.
