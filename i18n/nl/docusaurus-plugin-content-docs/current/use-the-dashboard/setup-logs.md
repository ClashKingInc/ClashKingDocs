# 📄 Logs instellen

Je kunt je logs instellen vanuit het dashboard. Zo kies je visueel welke logs je wilt en waar ze naartoe worden gestuurd.

## Logtypes

- [Clanlogs](../clan-setups/log-setup.md#clan-logs): leden die joinen/leaven, donaties, clanprestaties en instellingenwijzigingen.
- [War/CWL-logs](../clan-setups/log-setup.md#war-cwl-logs): war-updates, panels en CWL-opstellingswijzigingen.
- [Capital-logs](../clan-setups/log-setup.md#capital-logs): capital-donaties, aanvallen, panels en weekoverzichten.
- [Spelerlogs](../clan-setups/log-setup.md#players-logs): rol-, troop-, hero-, townhall-, league- en naamswijzigingen.

:::info
Voor een volledig overzicht van alle beschikbare logtypes, zie [📄 Log Setup](../clan-setups/log-setup.md).
:::
