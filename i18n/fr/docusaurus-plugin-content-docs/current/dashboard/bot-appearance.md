# 🎨 Apparence du bot

Utilisez **General settings** dans le tableau de bord pour configurer l'apparence du bot, l'analyse des liens et les accès de votre serveur.

## Personnaliser le profil du bot

Ouvrez **General settings** pour votre serveur et trouvez **Bot server profile**. Si la personnalisation est activée pour votre serveur, vous pouvez modifier le nom, la bio, l'avatar et la bannière du bot sur ce serveur. Les changements sont enregistrés depuis la carte de profil ; les boutons de réinitialisation rétablissent chaque élément du profil global. La modification nécessite le droit de gérer les paramètres. Si la fonction est verrouillée, utilisez le lien d'assistance affiché pour demander l'accès.

## Choisir la couleur des embeds

Sous **Appearance**, choisissez une couleur et consultez l'aperçu. Elle est utilisée pour les messages compatibles du bot. Les paramètres sont enregistrés dans le tableau de bord.

## Autres paramètres

- Configurez l'[accès au tableau de bord](dashboard-access.md) et le rôle délégué à l'actualisation des rôles sous **Security & Permissions**.
- Activez ou désactivez les types de liens compatibles sous **Link parsing** ; consultez [Link parsing](link-parsing.md).
- Activez les rôles d'ancienneté Discord dans **Lab** avant de les configurer ici ; consultez [Roles & Nicknames](roles-and-nicknames.md).
