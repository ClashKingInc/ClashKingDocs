# 😎 Paramètres utilisateur

Les utilisateurs peuvent définir eux-mêmes quelques paramètres. Pour l'instant, seulement 3 sont disponibles.

<figure><img src="/img/gitbook/image (89).png" alt="" /><figcaption></figcaption></figure>

* `{default_main_account}` vous permet de choisir quel compte sera affiché en premier lorsque vous exécuterez une commande spécifique (par exemple `/player lookup`).
* `{server_main_account}` vous fait choisir quel compte sera affiché en premier lorsque vous exécuterez une commande spécifique **mais uniquement sur le serveur actuel** (par exemple `/player lookup`).
* `{private_mode}` : si vous voulez être un ninja (inutile pour le moment).
