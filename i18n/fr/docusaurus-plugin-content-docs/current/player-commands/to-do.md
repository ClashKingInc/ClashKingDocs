# 🤔 À faire

La commande `/player to-do` montre ce que vous devez faire aujourd'hui sur tous vos comptes. Cela inclut les succès des Légendes, les succès des Raids, les points des Jeux de Clan, les points du Season Pass, les dons de capital et l'inactivité.
