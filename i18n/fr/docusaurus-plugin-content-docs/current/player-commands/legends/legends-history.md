# Histoire des légendes

Ceci montre les trophées EOS (fin de saison) d'un joueur depuis qu'il a été suivi pour la première fois par le bot.

## La commande

`/legends history {player}`

## Le paramètre

* `player` : recherche par nom ou tag du joueur.
