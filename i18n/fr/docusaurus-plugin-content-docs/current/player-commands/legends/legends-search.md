# Recherche de légendes

## La commande

`/legends search {player}`

## Le paramètre

* `player` : recherche par nom ou tag du joueur.

## Explication

Sous l'intégration, vous trouverez plusieurs boutons :\
![](</img/gitbook/image (158).png>)

Le bouton "Aujourd'hui", qui est la vue par défaut, vous montrera le nombre d'attaques/defenses, les trophées que vous avez gagnés/lost, les classements mondiaux et nationaux, les trophées par attaque et défense, l'équipement du héros utilisé, et une image sera générée pour résumer ces informations.\
![](</img/gitbook/image (157).png>)
:::info
Lisez d'abord la FAQ si vous pensez que les statistiques de la légende sont fausses : [FAQ](../../faq.md)
:::

Le deuxième bouton affichera vos résultats quotidiens depuis le début de la saison\
![](</img/gitbook/image (161).png>)

Le troisième bouton affichera vos trophées EOS puisque le bot suit les statistiques de votre profil :![](</img/gitbook/image (163).png>)\


Le dernier bouton ajoutera le profil à la liste Quick Check & Daily Report (inutile pour le moment).
