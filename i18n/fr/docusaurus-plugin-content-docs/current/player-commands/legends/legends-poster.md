# Affiche Légendes

Ceci envoie l'image qui est affichée dans `/legends search`

## La commande

`/legends poster {player} {background}`

## Le paramètre

### Requis

* `player` : recherche par nom ou tag du joueur.

### Facultatif

* `background` : changez l'image de l'image.
