# 📄 Configurer les logs

Vous pouvez configurer vos logs depuis le tableau de bord. Cela vous permet de choisir visuellement quels logs vous souhaitez et où ils doivent être envoyés.

## Types de logs

- [Logs de clan](../clan-setups/log-setup.md#clan-logs) : arrivées/départs de membres, dons, réussites du clan et changements de paramètres.
- [Logs de guerre/CWL](../clan-setups/log-setup.md#war-cwl-logs) : mises à jour de guerre, panneaux et changements de composition CWL.
- [Logs de capitale](../clan-setups/log-setup.md#capital-logs) : dons de capitale, attaques, panneaux et résumés hebdomadaires.
- [Logs de joueurs](../clan-setups/log-setup.md#players-logs) : changements de rôle, troupe, héros, hôtel de ville, ligue et nom.

:::info
Pour un aperçu complet de tous les types de logs disponibles, voir [📄 Log Setup](../clan-setups/log-setup.md).
:::
