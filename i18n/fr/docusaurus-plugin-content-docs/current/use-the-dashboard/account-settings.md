# 👤 Account Settings

Utilisez **Account Settings** pour gérer vos préférences du tableau de bord et consulter les informations du serveur.

## Profil et apparence

Ouvrez **Settings** depuis le menu de votre compte. Sous **Profile**, choisissez le thème et la langue du tableau de bord ou suivez le thème du système et la langue du navigateur. Vous pouvez aussi masquer les invitations à soutenir le projet. Ce sont des préférences du tableau de bord.

## Server et Lab

Lorsqu'un serveur est sélectionné, **Server** affiche ses limites de ressources. **Lab** est accessible aux personnes pouvant consulter les paramètres du serveur et contient les fonctions expérimentales. Vous pouvez actuellement y activer les rôles d'ancienneté Discord, puis les configurer sous **General settings** ; consultez [Roles & Nicknames](../players-roles/roles-th-and-more/README.md). La gestion de l'expérience nécessite le droit de gérer les paramètres.
