# ➕ Ajouter un clan

Sous **Management** dans le tableau de bord, vous pouvez ajouter un clan à votre serveur. Cela vous permet de gérer ce clan et ses paramètres depuis le tableau de bord plutôt que uniquement via les commandes Discord.

## Vérifier un clan

Pour prouver qu'un clan appartient à votre serveur, ajoutez temporairement un mot de vérification à la description du clan dans le jeu.

Une fois le clan vérifié :

- Les liens de comptes cachés dans la liste du clan deviennent visibles.
- Les gestionnaires de liens du tableau de bord peuvent ajouter ou supprimer des liens non vérifiés pour ses membres.
- Les liens de joueurs déjà vérifiés restent protégés.

Après la réussite de la vérification, vous pouvez retirer le mot de la description du clan.
