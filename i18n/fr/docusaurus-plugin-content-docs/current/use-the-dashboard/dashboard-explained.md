# 🖥️ Tableau de bord expliqué

Le **tableau de bord** permet de gérer facilement les paramètres de votre serveur Discord pour ClashKing en un seul endroit. Certains paramètres qui étaient auparavant configurés via le bot Discord ont été déplacés vers le tableau de bord.

## Accéder au tableau de bord

Vous pouvez accéder au tableau de bord de deux façons :

- Allez sur [https://clashk.ing/login](https://clashk.ing/login)
- Utilisez la commande `/setup` dans un serveur Discord où ClashKing est installé

:::info
ClashKing doit être présent sur votre serveur. L’accès nécessite la propriété du serveur, **Manage Server**, **Administrator** ou un rôle disposant d’un [accès au tableau de bord](../server-setups/whitelist.md).
:::

Utilisez le tableau de bord pour configurer vos paramètres Discord plus facilement.
