# 📊 Analytics

Analytics présente l'activité et les tendances enregistrées pour les clans associés à votre serveur. Cette fonction est en **bêta**.

## Explorer le tableau de bord

Ouvrez **Management → Analytics** et choisissez une période prédéfinie ou personnalisée. Sélectionnez éventuellement un clan pour limiter le rapport. Ajoutez d'abord des clans au serveur si aucun n'est disponible ; consultez [Add / Setup a clan](add-a-clan.md).

Le rapport comprend notamment les effectifs et mouvements, la répartition des hôtels de ville et des ligues, les comparaisons de clans, les activités et améliorations enregistrées et les résultats Légende disponibles. Choisissez une statistique pour modifier le calendrier d'activité et le classement des joueurs. Cliquez sur un jour ou un joueur pour voir les détails ; utilisez la recherche et la pagination pour les longues listes.

Par exemple, sélectionnez un clan et une période pour comparer les dons ou l'activité de farming enregistrés. Le rapport utilise des observations suivies : une donnée manquante ne signifie pas nécessairement une activité nulle. Les statistiques de liaison apparaissent si vous pouvez consulter Links.
