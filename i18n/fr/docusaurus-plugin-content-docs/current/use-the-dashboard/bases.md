# 🗺️ Bases

Utilisez **Management → Bases** dans le tableau de bord pour publier et gérer les bases de votre serveur. Cette page nécessite un accès complet au tableau de bord.

## Publier une base

1. Ouvrez **Bases** et choisissez **Create**.
2. Sélectionnez un salon Discord, saisissez le lien de base Clash of Clans et une description, puis ajoutez les captures d'écran requises.
3. Envoyez le formulaire et vérifiez le résultat. Les membres peuvent obtenir le lien et voter sur le message Discord.

Par exemple, indiquez le niveau d'hôtel de ville et si la base sert à la guerre ou au farming. Vous pouvez aussi publier une base dans Discord avec [`/base`](link-parsing.md).

## Gérer les bases publiées

La liste affiche les captures disponibles, les téléchargements et les votes. Ouvrez la base ou le message Discord, consultez l'historique des téléchargements, modifiez une base ou supprimez-la avec les commandes correspondantes. Vérifiez la confirmation avant de supprimer. Utilisez l'actualisation et la pagination pour parcourir la liste.
