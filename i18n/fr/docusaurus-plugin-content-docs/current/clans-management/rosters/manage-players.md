# ↔️ Gérer les joueurs

## Le but

Si vous souhaitez modifier le contenu d'une liste sans utiliser de [post-a-roster-signup-and-more.md](post-a-roster-signup-and-more.md "mention"), vous pouvez alors utiliser des commandes pour ajouter ou déplacer des joueurs.

[#add-players](manage-players.md#add-players "mention")

[#move-or-remove-players](manage-players.md#move-or-remove-players "mention")

## Ajouter des joueurs {#add-players}

C’est un moyen simple d’ajouter une seule personne à une liste.

### La commande

Utilisez `/roster add-player`&#x20;

### Paramètres

* `roster` : nom de la liste à laquelle vous souhaitez ajouter le joueur
* `player` : nom ou tag du joueur

## Déplacer ou supprimer des joueurs {#move-or-remove-players}

Il permet de déplacer un joueur entre deux rosters ou de le supprimer d'un seul.

Vous pouvez basculer entre le mode supprimer et déplacer le joueur en utilisant le bouton d'engrenage.

![](</img/docs-media/image (9) (1).png>)

### La commande

Utiliser `/roster move-player`

### Paramètres

`roster` : Nom de la liste à laquelle vous souhaitez ajouter le joueur
