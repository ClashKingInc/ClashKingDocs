# 🆘 Aide

La commande `/help {command} {category}` affiche une documentation rapide pour une commande spécifique directement dans Discord. Vous pouvez rechercher une commande ou une catégorie spécifique, ou parcourir la documentation complète à l'aide du menu déroulant.
