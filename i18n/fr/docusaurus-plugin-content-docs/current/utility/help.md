# 🆘 Aide

Utilisez `/help` pour parcourir les commandes Discord disponibles de ClashKing et découvrir leur fonctionnement.

## Parcourir les commandes

Exécutez `/help` sans option pour afficher la liste des commandes. Dans le menu **Browse commands**, choisissez une catégorie, comme **Players & rankings**, **Clans & wars** ou **Your accounts**. Choisissez **All commands** pour revenir à la liste complète. Le bouton d'actualisation met à jour la vue actuelle.

## Trouver une commande

Utilisez le champ facultatif **command** et sélectionnez une commande actuelle parmi les suggestions de Discord. Par exemple, choisissez `link add` pour voir la description de `/link add`. Une commande comportant des sous-commandes affiche celles disponibles ; une sous-commande précise affiche sa description et ses champs obligatoires ou facultatifs.

Vous pouvez aussi utiliser le champ facultatif **category** pour ouvrir directement une catégorie. Pour des guides plus détaillés, consultez le reste de cette documentation.
