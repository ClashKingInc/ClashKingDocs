# 🤖 Informations du bot

Utilisez `/bot` pour voir les statistiques de ClashKing et des liens utiles.

## Consulter les statistiques

Lancez `/bot` pour voir les nombres disponibles, comme les serveurs, les clans liés, les joueurs et clans suivis et les guerres enregistrées. D'autres nombres apparaissent lorsqu'ils sont disponibles. Utilisez le bouton d'actualisation pour mettre les statistiques à jour, ou **Bot Invite** et **Support Server** pour ouvrir les liens correspondants.
