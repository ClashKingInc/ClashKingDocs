# 🎫 Tickets

Les tickets peuvent être configurés sur le tableau de bord. Depuis Discord, vous pouvez les gérer avec les commandes suivantes.

## /ticket status

Utilisez `/ticket status` avec l'un de ces arguments :

- `open`
- `sleep`
- `close`

## /ticket add

Utilisez `/ticket add` avec un argument **player** pour ajouter quelqu'un à un ticket.

## /ticket messages

Utilisez `/ticket messages` pour envoyer facilement des messages préparés dans Discord. Préparez ces messages d'abord sur le tableau de bord.
