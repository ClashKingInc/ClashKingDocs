# 📋 Commandes de roster

Utilisez ces commandes Discord pour publier un roster existant ou trouver les rosters d'un joueur. Créez et gérez les rosters dans le [tableau de bord](../clans-management/rosters/README.md).

## `/roster post`

Publiez un roster existant dans le salon actuel. Sélectionnez le **roster** et un **type** :

- **Signup** : avec des boutons pour s'inscrire ou retirer une inscription.
- **Post** : affiche le roster sans boutons d'inscription.
- **Static** : publie un instantané.

Cette commande nécessite la permission **Gérer le serveur** ou **Administrateur**. Vous pouvez aussi publier depuis le tableau de bord et y choisir la destination.

## `/roster search`

Recherchez dans les rosters de ce serveur un **player** (sélectionnez un tag de joueur) ou un **user** (sélectionnez un utilisateur Discord). Choisissez l'un des deux ; sans choix, la commande recherche vos propres comptes liés visibles.
