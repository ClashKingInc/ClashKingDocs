# 👥 Membres par rôle

Utilisez `/role-users` dans un serveur Discord pour lister les membres ayant un rôle Discord précis.

## Trouver les membres d'un rôle

Lancez `/role-users` et sélectionnez le **role** obligatoire. Par exemple, sélectionnez un rôle de direction pour voir quels membres du serveur le possèdent. Le résultat indique le nombre de membres ; utilisez les boutons de navigation pour les longues listes et le bouton d'actualisation pour mettre le résultat à jour.

Pour configurer les rôles automatiques de ClashKing, consultez [Roles & Nicknames](../players-roles/roles-th-and-more/README.md).
