# 📈 Graphs

Utilisez `/graph` pour explorer les statistiques de clan et de famille.

## Commande

- **Commande :** `/graph`
- **Description :** `Explore clan and family statistics`

La commande prend en charge **3 paramètres optionnels**.

## Options

| Paramètre | Description |
|---|---|
| `attribute` | Statistique (par défaut : Activity) |
| `clan_category` | Catégorie de clan familial (par défaut : tous les clans de la famille) |
| `limit` | Clans à comparer (par défaut : 5) |

## Valeurs par défaut

- `attribute` : `Activity`
- `clan_category` : tous les clans de la famille
- `limit` : `5`
