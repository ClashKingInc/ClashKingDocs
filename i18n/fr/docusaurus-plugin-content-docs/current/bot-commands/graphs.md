# 📈 Graphs

Utilisez `/graph` sur votre serveur Discord pour comparer les statistiques des clans de votre famille. [Ajoutez d'abord les clans au serveur](../use-the-dashboard/add-a-clan.md) ; vous pouvez aussi leur attribuer une catégorie.

## Utiliser la commande

Les trois options sont facultatives :

- **attribute** : choisissez une statistique. La valeur par défaut est **Activity**.
- **clan_category** : limitez les clans de la famille à une catégorie. Laissez vide pour tous les clans de la famille.
- **limit** : choisissez le nombre initial de clans à comparer, de **1 à 5**. La valeur par défaut est **5**.

Par exemple, utilisez `/graph` pour afficher l'activité, ou choisissez **Donations** et une catégorie de clans pour comparer les dons de ce groupe. Sans option, Activity s'ouvre sur une tendance quotidienne des 30 derniers jours.

## Modifier le graphique

Les commandes sous le graphique permettent de modifier **Statistic**, **Chart view** ou les clans sélectionnés sans relancer la commande. Le menu des clans permet de choisir des clans individuellement ou de revenir à tous les clans de la famille ou de la catégorie. Le bouton d'actualisation recharge la vue actuelle.

Selon la statistique, les vues suivantes sont disponibles :

- **Daily trend** : comparez les valeurs quotidiennes sur 7, 30, 90 ou 180 jours.
- **Season totals** : comparez les totaux de la saison actuelle ou d'une saison choisie.
- **Season trend** : comparez les tendances sur 2, 4, 6 ou 12 saisons. La ligue CWL utilise cette vue.

## Statistiques disponibles

Choisissez parmi l'activité, les améliorations, les dons, les troupes reçues, les arrivées et départs, l'or de capitale donné ou pillé, l'or, l'élixir et l'élixir noir pillés, les étoiles de guerre, le taux de victoire, les guerres gagnées ou lancées et la ligue CWL. Les tendances quotidiennes sont disponibles pour l'activité, les améliorations, les dons, les troupes reçues, l'or de capitale donné et les arrivées et départs.

:::info
Les graphiques dépendent des données enregistrées disponibles. Certains totaux de clan ou historiques peuvent manquer.
:::
