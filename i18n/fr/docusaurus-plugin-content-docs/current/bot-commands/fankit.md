# 🎨 Fankit

Utilisez `/fankit` pour rechercher les images de jeu ClashKing, notamment les troupes, les héros et les bâtiments.

## Rechercher une image

Utilisez `/fankit` et saisissez une **query**, par exemple `Archer Queen`. Le résultat montre les images correspondantes. Utilisez **Previous** et **Next** s'il y a plusieurs pages.

Dans un serveur, utilisez **Add Emoji** à côté d'une image pour l'ajouter comme emoji du serveur. Vous et le bot devez pouvoir créer des expressions et le serveur doit disposer d'un emplacement d'emoji libre. Le bouton est indisponible hors d'un serveur.
