# 🐸 Memes

Utilisez `/meme` pour créer un meme sur le thème de Clash ou une pancarte Pepe avec votre texte.

## Créer un meme

1. Lancez `/meme` et sélectionnez un modèle dans **Choose a meme template**.
2. Saisissez les textes et envoyez le formulaire.
3. Enregistrez ou copiez l'image générée pour la partager. Utilisez **Write again** pour modifier le texte ou choisissez un autre modèle.

Par exemple, choisissez **Pepe sign** et saisissez le texte de la pancarte. L'aperçu n'est visible que par vous jusqu'au partage de l'image.
