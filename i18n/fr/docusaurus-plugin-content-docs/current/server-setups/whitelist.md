# ⬜ Accès au tableau de bord

Les paramètres d'accès permettent d'autoriser des rôles Discord à consulter ou gérer certaines sections du tableau de bord ClashKing de votre serveur.

## Donner accès à un rôle

1. Ouvrez le tableau de bord ClashKing, sélectionnez votre serveur et ouvrez **General settings**.
2. Trouvez **Dashboard access** sous **Security & Permissions**. Cette section est accessible aux gestionnaires du serveur disposant d'un accès complet au tableau de bord.
3. Sélectionnez un rôle Discord et cliquez sur **Add role**. Un nouveau rôle reçoit initialement l'accès **View** aux paramètres généraux.
4. Pour chaque section disponible, choisissez **No access**, **View** ou **Manage**. Les modifications sont enregistrées automatiquement ; vérifiez que l'état **Saved** apparaît.

**View** permet de consulter une section ; **Manage** permet également de modifier ses paramètres. Les accès de plusieurs rôles se cumulent. **No access** retire l'accès accordé par ce rôle à une section ; un autre rôle peut toujours l'accorder.

Pour retirer tous les accès d'un rôle au tableau de bord, utilisez la corbeille à côté de son nom. Pour retirer l'accès à une seule section, choisissez **No access** pour cette section.

## Rôle délégué pour l'actualisation

Sous **Security & Permissions**, le paramètre distinct **Role refresh delegate** permet de choisir un rôle Discord dont les membres peuvent actualiser les rôles d'autres utilisateurs. Choisissez **No Role** pour le supprimer. Ce paramètre n'accorde pas de permissions de tableau de bord ou de modération ; l'accès au tableau de bord n'accorde pas automatiquement cette permission d'actualisation.
