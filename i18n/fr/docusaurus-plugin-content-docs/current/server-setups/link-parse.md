# 🏹 Link parsing

L'analyse des liens transforme les liens Clash of Clans pris en charge en embeds visuels dans Discord.

## Configurer l'analyse des liens

1. Ouvrez le tableau de bord ClashKing et sélectionnez votre serveur.
2. Ouvrez **General settings** et cherchez **Link parsing**.
3. Activez ou désactivez chaque option : **Clan links**, **Army links**, **Player links**, **Base links** et **-show commands**. Les modifications sont enregistrées depuis le tableau de bord.
