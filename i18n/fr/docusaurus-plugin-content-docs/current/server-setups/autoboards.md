# 🏗️ Autoboards

Les autoboards maintiennent automatiquement des classements sur votre serveur Discord.

:::warning
Cette fonctionnalité est en **bêta ouverte**.
:::

## Classements disponibles

- **Donation leaderboard** : affichez les 1 à 50 meilleurs donateurs de votre famille ou de clans sélectionnés. Vous pouvez actualiser un message ou envoyer un nouveau message selon un planning.
- **Farming leaderboard** : affichez les 1 à 5 meilleurs membres actuels d'un clan sélectionné, selon les attaques de farming enregistrées. Choisissez la saison de jeu en cours ou une période glissante de 1 à 180 jours. Ce classement actualise un message.

## Créer un autoboard

1. Ouvrez le tableau de bord ClashKing, sélectionnez votre serveur et ouvrez **Autoboards**.
2. Cliquez sur **Create AutoBoard** et choisissez un type de classement.
3. Choisissez la famille ou les clans à inclure, selon le type de classement. Ajoutez d'abord les clans à votre serveur s'ils ne sont pas disponibles.
4. Choisissez un salon Discord et, si nécessaire, un fil ou une publication de forum. Une destination de type forum nécessite une publication.
5. Définissez le nombre de joueurs à afficher. Pour le farming, choisissez aussi la période et, pour une période glissante, le nombre de jours.
6. Pour les dons, choisissez **Refresh** pour actualiser le même message, ou **Scheduled send** pour envoyer un nouveau message chaque jour, certains jours de la semaine ou un jour du mois. Les horaires sont en UTC.
7. Réglez l'intervalle d'actualisation si le tableau de bord le permet, choisissez si le classement est activé, puis cliquez sur **Create AutoBoard**.

## Gérer les autoboards

Le tableau de bord affiche les classements configurés et permet de les modifier, désactiver ou supprimer. Un classement désactivé conserve ses paramètres mais ne s'exécute pas. Pour avoir à la fois un classement des dons actualisé et des publications programmées, créez deux classements distincts.
