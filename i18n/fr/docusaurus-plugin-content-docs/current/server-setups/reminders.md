# 📳 Rappels

Configurez des rappels automatiques dans le tableau de bord pour les guerres, les week-ends de raids et les jeux de clan. Pour envoyer immédiatement un seul rappel sans planning, utilisez la [commande de rappel ponctuel](../bot-commands/reminders.md).

## Configurer un rappel automatique

1. Ouvrez le tableau de bord ClashKing, sélectionnez votre serveur et ouvrez **Reminders**. Ajoutez d'abord votre clan au serveur s'il n'est pas disponible.
2. Cliquez sur **Add Reminder** et choisissez **War**, **Clan Capital** ou **Clan Games**.
3. Sélectionnez le clan, le salon de destination et le temps restant avant la fin de l'événement auquel envoyer le rappel. Vous pouvez aussi choisir un fil ; un salon de forum nécessite une publication.
4. Ajoutez éventuellement un message personnalisé. Pour les guerres, sélectionnez les types de guerre ; pour la capitale ou les jeux de clan, choisissez le seuil d'attaques ou de points.
5. Cliquez sur **Add Reminder** pour enregistrer le rappel.

## Types de rappels

- **War** : rappelez les joueurs pendant les guerres normales, amicales ou de ligue. Choisissez les types de guerre concernés.
- **Clan Capital** : rappelez les joueurs qui disposent au moins du nombre d'attaques restantes choisi pendant le week-end de raids.
- **Clan Games** : rappelez les joueurs dont les points sont inférieurs au seuil choisi.

:::info
Le journal de guerre de votre clan doit être public dans Clash of Clans pour que les rappels de guerre fonctionnent.
:::

Associez les comptes Clash of Clans des joueurs à leurs comptes Discord pour pouvoir les mentionner dans les rappels. Consultez [Associer les joueurs](../clan-setups/link-players/).

## Gérer les rappels

Utilisez le filtre de clan et les onglets pour retrouver les rappels configurés. Vous pouvez les modifier, les supprimer, les copier vers un autre clan ou demander un envoi immédiat avec **Send now**. Le tableau de bord confirme l'acceptation de la demande ; la livraison n'est pas garantie.
