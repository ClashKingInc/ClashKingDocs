# 🟢 Allumez-le !

Donc, si vous êtes ici, vous devriez avoir tout fait dans le guide [Developer Portal](developer-portal.md) et devriez avoir votre jeton de bot et votre lien d'invitation de bot (ne l'utilisez pas _encore_).\
\
Revenez maintenant à Discord, dans un canal où vous pouvez exécuter des commandes ClashKing, utilisez `/setup custom-bot`. Cela a 2 options.

* nom : ceci est juste un nom à des fins d'identification, faites-en quelque chose de mémorable, donc si vous avez besoin que je regarde le bot personnalisé "coolbot9000", je peux le faire, cela ne changera pas le nom que vous avez défini sur le bot plus tôt.
* bot\_token : il s'agit du jeton de la configuration précédente que vous auriez dû enregistrer

Remplissez les deux champs, exécutez la commande et vous devriez recevoir un message du type & #x20;

```
"Bot created, will be online shortly"
```

Vous pouvez maintenant inviter votre bot. Utilisez le lien d’invitation que vous avez enregistré précédemment. En cliquant dessus, vous pouvez l'inviter sur votre serveur comme les autres robots.\


Si vous décidez de modifier le nom de la photo de profil de votre bot, vous pouvez le faire de la même manière que vous l'avez défini initialement.

:::danger
Ne placez pas 2 robots personnalisés ClashKing sur un seul serveur. Ce ne sera pas joli. Cependant, avoir le bot principal de ClashKing et votre version personnalisée est tout à fait acceptable, et je l'encouragerais même peut-être si cela ne dérange rien.
:::
:::tip
Le bot prendra quelques minutes pour s'initialiser, créant des emojis, etc. Donc, si vous voulez attendre pour inviter le bot 10 minutes après la création, ce n'est pas grave.
:::
